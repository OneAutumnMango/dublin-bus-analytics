# Stats Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-optimized:subagent-driven-development (recommended) or superpowers-optimized:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add a per-route `#/lab/{route}` page showing delay distribution, persistence along the trip and variance decomposition, each with a plain-English explanation and day-block bootstrap uncertainty.

**Architecture:** A new pure module `app/analysis/lab.py` (numpy/scipy, no I/O) holds all statistics. Three read-only endpoints in `app/api/routes.py` collect rows with the existing `_heavy`/`_scan_arrivals` machinery and call it. A new plain-ES-module page `web/js/pages/lab.js` renders them with new chart code in `web/js/labcharts.js` and text in `web/js/labtext.js`. Nothing is stored; results are computed per request.

**Tech Stack:** Python 3.12, FastAPI, numpy, scipy, SQLite; plain ES modules (no build); pytest, `node --test`.

**Spec:** `docs/specs/2026-11-13-stats-lab-design.md`

**Assumptions:**
- Assumes `arrivals.service_date` is a non-null `YYYY-MM-DD` text and identifies one Dublin service day. Will NOT work if rows lack it; rows with a null date are grouped as one day `""`.
- Assumes stop order comes from the server (`_directions`), as for `/accumulation`. Will NOT work for persistence when the server is unavailable; persistence then returns `order_source: "none"` and no figures.
- Assumes one process, as the README requires (the heavy-request gate is per process).

## Global Constraints

- Models for subagents: sonnet or cheaper only, never opus. At most 2 agents at once. Run Python under `ulimit -v 2500000`; run `tests/api/test_routes.py` alone, not alongside other heavy files.
- Commit at the end of every task (the project convention), never skip commits.
- Statistics modules are pure: no I/O, no db/model imports; invalid *parameters* raise `ValueError`; degenerate *data* yields `None` fields, never NaN/inf (`stats.py` convention).
- `low_n` means n < 10 (existing `LOW_N`). Delays are seconds (actual minus scheduled); the UI shows minutes.
- Bootstrap: resample whole Dublin service days with replacement, 200 resamples (`BOOT_B`), fixed seed (`BOOT_SEED = 20261113`), percentile CI at the request's `ci` level. With fewer than 5 days (`MIN_DAYS`) the CI is `null` and the UI says "not enough days yet".
- Endpoints take the same query parameters as the other route endpoints (`P`), echo `filters`, run through `_heavy`, and return through `_clean` so no NaN/inf is emitted.
- The UI uses plain ES modules, no build step, escapes all text through the `h` helper (never `innerHTML`), and gives every chart a data table like the Analytics page.
- Every plot and tile has an open-by-default "What am I looking at?" explanation in plain English, plus a one-line reading of the current result.
- No server (`dublin-bus-server`) change. Out of scope: per-stop picker, forecast skill, headways, trend charts, weather.

## Review Focus

- A route with data on only 1 to 4 days: CI is `null`, no crash, message shown (Tasks 2, 5, 11).
- All delays identical (zero variance): skew, kurtosis, omega-squared, autocorrelation are `null`, not NaN; the QQ plot still draws (Tasks 1, 3, 9).
- A filter that leaves zero rows: HTTP 200 with `n: 0`, empty arrays, empty state in the UI (Tasks 5, 6, 7, 11).
- Server unavailable: persistence returns `order_source: "none"` (200, not 500) while distribution and variance still work (Tasks 6, 7).
- A loop route (stop repeated within a trip): persistence uses `_assign`'s matching and never counts an ambiguous stop twice (Task 4, 7).

### Task 3: Persistence and variance statistics

**Files:**
- Modify: `app/analysis/lab.py`
- Test: `tests/analysis/test_lab.py`

**Interfaces:**
- Consumes: nothing from earlier tasks
- Produces:
  - `autocorr_by_lag(trips, max_lag: int = 5) -> dict[int, dict]`. `trips`: list of trips, each a list of `(position: int, delay: float)` with strictly increasing positions. For each lag 1..`max_lag`, pools all pairs of the same trip whose positions differ by exactly the lag and returns `{lag: {"r": Pearson r | None, "n": pair count}}`. `r` is `None` when n < 3 or either side has zero variance. `max_lag < 1` raises ValueError.
  - `recovery_slope(trips) -> dict`: `{"slope": float | None, "n": int}`. Pairs are (delay at the trip's first position, delay at each later position) for every trip with at least two points; slope is the least-squares slope of later on first; `None` when n < 3 or the first-position delays have zero variance. Slope near 1 means a delay persists; near 0 means the bus recovers.
  - `omega_squared(codes, y) -> float | None`. `codes`: integer numpy array of group labels, `y`: float numpy array, same length. Adjusted one-way ANOVA effect size `(SSB - (k-1)*MSW) / (SST + MSW)`, clamped at 0. `None` when k < 2, N - k < 1, or SST == 0. Length mismatch raises ValueError.

**Security flag:** `none`
**Does NOT cover:** a joint model of hour, weekday and stop; these effect sizes overlap and are not additive.

- [x] **Step 1: Write failing tests:**
  - `test_autocorr_perfectly_persistent_trips`: 30 trips, trip `j` has delay `j*10` at positions 0..5 -> for lags 1..5, `r == pytest.approx(1.0)`, and `n` for lag 1 is 150.
  - `test_autocorr_independent_delays_near_zero`: 2000 trips of iid `default_rng(2).normal` at positions 0..5 -> `abs(r) < 0.1` for lag 1.
  - `test_autocorr_only_exact_position_gaps_pair`: one set of trips with positions `[0, 2, 3]` -> lag 1 uses only the (2,3) pairs (`n == number of trips`), lag 2 only (0,2), lag 3 only (0,3).
  - `test_autocorr_degenerate`: constant delays -> `r is None`; fewer than 3 pairs -> `r is None`; `max_lag=0` raises ValueError.
  - `test_recovery_slope`: trips with later delays `0.5 * first` -> `slope == approx(0.5)`; later `== first` -> `approx(1.0)`; identical first delays across trips -> `None`.
  - `test_omega_separated_groups`: `y = codes*10 + small noise`, 5 groups x 100 -> `> 0.95`.
  - `test_omega_independent_near_zero`: `y` iid, random codes -> `0 <= omega < 0.02`.
  - `test_omega_degenerate`: single group, `N == k`, constant `y` -> `None`; length mismatch raises ValueError.
