# Map Page Implementation Plan

> **For agentic workers:** executing-plans, inline, Sonnet only, one review at the end, commit per task (group commits sensibly).

**Goal:** `#/map` page showing tracked routes' stops coloured by lateness with regions, route toggles, tooltips and a time window.
**Architecture:** new `/api/map` endpoint; pure `js/mapdata.js` (scale, hexes, geojson); `js/slider.js`; shared tooltip API; thin `pages/map.js` driving MapLibre.
**Tech Stack:** FastAPI/SQLite (Python 3.12, `.venv/bin/python -m pytest`), vanilla ES modules, MapLibre GL JS (vendored).
**Spec:** docs/specs/2026-11-10-map-design.md
**Assumptions:** desktop browser with WebGL; OpenFreeMap reachable (map degrades gracefully if not).

## Global Constraints
- Web: `cd web && (ulimit -v 2500000; node --test test/)`; Python: `(ulimit -v 2500000; .venv/bin/python -m pytest -q -p no:cacheprovider)` with coverage fail_under 90 as configured.
- No innerHTML; Okabe-Ito colours only (`#0072B2` blue, `#E69F00` orange); contrast tests pass; CSP exactly as in the spec.

## Review Focus
- `minutes_from > minutes_to` wraps midnight; equal values mean a single minute, not all day (Task 1 tests).
- Stops listed by several routes / directions are combined once (Task 1, 3 tests).
- Hex cells with a single stop or tiny n never render (Task 3 test).
