How to read the numbers
  • Delay is actual arrival minus scheduled arrival. Negative = early, positive = late. The API stores seconds; the UI shows minutes with one decimal (seconds when under a minute).
  • On time uses a window around the schedule (default 1 min early to 5 min late, configurable).
  • Percentile band (default 5th to 95th): that share of buses arrived within it. Confidence interval (default 95 %): where the long-run average delay lies; it narrows as n grows.
  • n is the number of arrivals behind a number. Values with n below 10 are greyed out: too few to trust.
  • Dates are interpreted in UTC; hours and weekdays use Dublin local time.
